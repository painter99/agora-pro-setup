# Suffix Tab: User Message Enclosure

In the Agora app, switch to the **Suffix Tab** in the System Prompt editor. This closes the user message XML wrapper cleanly.

Here is the single block I use:

---

### Block 1: Text Block
*Paste the following closing XML tag (ensure you keep the blank newline before the text):*

```text

</agora_user_message>
```
