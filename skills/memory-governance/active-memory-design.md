# Skill: Active Memory Design

## Catalog description

Keeps always-available Active Memory compact, current, and useful.

## Purpose

Define what deserves the recurring token cost of Active Memory.

## Load when

- deciding whether content belongs in Active Memory;
- reviewing Active Memory size or structure;
- separating current context from Saved Memory or Skills.

## Do not load when

- reading a Saved Memory without changing placement;
- handling purely transient conversation context.

## Dependencies

`memory-master-index.md` for routing.

## Workflow

Keep only current status, durable communication preferences, active priorities, short anchors, and essential memory boundaries. Move long histories, detailed specifications, complete workflows, static reference material, and dormant information to Saved Memory. Keep reusable procedures in Skills.

## Forbidden behavior

Do not place complete tool manuals, research procedures, session logs, copied web results, duplicate file bodies, speculative facts, or unrelated history in Active Memory.

## Verification

Check that Active Memory is compact, current, readable, and free of duplicated long-form content.

## Output contract

Recommend the correct destination for each reviewed item and identify content that should be removed or moved.
