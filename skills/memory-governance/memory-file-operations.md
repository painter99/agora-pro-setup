# Skill: Memory File Operations

## Catalog description

Safe creation, editing, renaming, archiving, and deletion of Saved Memory files.

## Purpose

Apply precise and reversible Saved Memory file operations.

## Load when

- creating, updating, renaming, archiving, or deleting a Saved Memory file;
- checking names, duplicates, or references.

## Do not load when

- only reading a file;
- changing an Agora Skill;
- answering a transient question.

## Dependencies

`memory-master-index.md` and the current Agora Memory tool reference.

## Workflow

1. List or read the current files.
2. Check for duplicates and exact names.
3. Use the smallest complete create or precise unique patch.
4. Preserve unrelated content.
5. Require approval before deletion or irreversible replacement.
6. Verify file contents, existence, and dependent references.

## Forbidden behavior

Do not invent files, silently delete data, overwrite when a precise patch is sufficient, or claim success without reading the result.

## Verification

Confirm the expected file state and that no Active Memory or documentation reference is broken.

## Output contract

Report the exact file operation and its verified result.
