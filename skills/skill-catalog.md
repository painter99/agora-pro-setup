# Skill Catalog Guidance

The native Agora Skill Catalog is provided through `{skill_catalog}` when Skill access is enabled.

## Catalog entry

Use a short description such as:

```text
research-multi-source.md — proportional workflow for current and disputed claims
```

## Catalog principles

- Name each Skill precisely.
- Keep descriptions short enough for repeated request injection.
- Describe the task the Skill performs, not its entire contents.
- Do not include secrets, long history, or personal data in descriptions.
- Read the Skill body before claiming to apply it.
- Do not load unrelated Skills.

A manual Active Memory registry may document recommended Skills for readers, but it must not pretend to replace Agora's native catalog.
