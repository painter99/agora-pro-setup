# Models and inference

This repository does **not** prescribe one best model. Dated personal stacks belong in *your* Active Memory, not in a public kit.

## Selection criteria

- tool-calling reliability (Skills + Memory + shell)
- instruction following on long kernels
- latency and cost
- context size
- vision / documents
- privacy / hosting
- stability when `{active_memory}` + `{skill_catalog}` + tools are present

## Sampling

Sampling changes style, not knowledge. Start moderate; test on *your* task set.

Record: model version, provider, date, parameters, tasks, method.

Separate independent benchmarks, vendor claims, proxy numbers, and personal notes. A leaderboard score is not an agent SLA.
